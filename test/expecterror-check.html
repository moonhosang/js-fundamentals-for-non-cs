🧪 expectError (repair drill) 검증 — ▶ 눌러 배너 확인

기대: 처음 실행 시 🎯(expected). 안내대로 고쳐 다시 실행하면 ✅(pass). 마지막 칸은 일부러 다른 에러 → ⚠️(mismatch).

① undefined.x → Cannot read properties (고치기: .title 앞에 ? 넣기)

② 매개변수 지역 → is not defined (고치기: 반환값 받아 쓰기)

③ const 재할당 → Assignment to constant (고치기: const→let)

④ 중괄호 짝(SyntaxError) → expectError:true (고치기: } 한 줄 추가)

⑤ [대조군] 이미 고쳐진 코드 → 처음부터 ✅ pass 여야 함

⑥ [대조군] 예상과 다른 에러 → ⚠️ mismatch 여야 함
