## ②-A 드릴 개수 (ADR 0008: 쉬움5·보통5·어려움5=15)

### 🟩 F-DRILL-CNT [Info] 모든 챕터 ≥5/티어 · **미달 0** · 일부 의도적 초과
28개 base × 3티어 집계: **5개 미만 티어 0건**(모든 챕터 3티어 완비). 정확히 15인 챕터 다수. 초과:
- **5(함수) 8/9/8=25** · **8(객체) 6/6/6=18** · **objprim(조화) 6/8/12=26**
→ 합성·대형 챕터라 의도적 확장으로 판단(문제 아님). **다만 ADR 0008 문구가 "= 15"라 초과 챕터와 불일치** → 문구를 "**티어당 ≥5**(대형 챕터는 더)"로 완화 권장.

### 🟩 F-DRILL-BUG [Low·correctness] `easy.js` 1강 "복사는 독립" — explain 값 오류
```
code: let a = 5 / let b = a / b = 9 / print(a === ____)   answer: "5"
explain: "...b를 바꿔도 a의 셀은 그대로 10."   ← a=5인데 "10"이라 씀(오답 서술)
```
`let y=x`(a=10) 템플릿에서 복붙되며 값만 안 바꾼 흔적. → **explain "10"→"5"** 로 수정(즉시).

## ②-B POE(예측-관찰-설명) · 답 노출

### 🟩 F-POE [Good] POE 패턴 만연 · egregious 답노출 0
- `print(… === ____)` 예측 빈칸 **448곳**. 전 챕터 예측형 관철.
- 답노출 자동스캔 16건 표본 판정 → **전부 양성**: (a) 입력값이 답과 우연히 일치(`a[1]` 문제의 `[10,20,30]`·alias 문제의 "지훈"=입력), (b) hard 티어 유도 스캐폴딩(`2>1>0` 기전 설명). *"목표만 주고 답은 숨겨라"* 규범 잘 지켜짐(design-principles가 명시한 잔여 7건 수준과 부합).
