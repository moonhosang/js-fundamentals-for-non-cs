**커리큘럼은 견고하다.** 모델 규율(model B·B34)은 텍스트·config·실렌더 3층에서 무결(치명 위반 0). 약속된 레슨은 **전부 구현**(문서가 오히려 뒤처짐). POE·드릴 3티어·시각화 규범 잘 지켜짐. 발견은 **대부분 문서/색인 드리프트와 국소 다듬기** — 커리큘럼 뼈대를 흔드는 결함 없음.

④ 개념 갭(결함 아닌 결정)은 **스코프 A로 4종 구현 완료**(구조분해·에러·JSON·비동기). 남은 건 전용 심화 파트(마이크로태스크 등)뿐.

### 비동기 드릴 노트 (정직한 제약)
`async`는 **값-예측 Drill 없음** — 비동기는 "값 하나 예측"보다 "실행 순서 예측"이 핵심이고 `await`은 sync `new Function` 본문서 불가. → 순서는 **인라인 Quiz**로, 실제 순서는 **Runner**로 확인(포맷 강제 대신 매체를 맞춤).
