# 🧒 입문자 리마인드 체크리스트

> **쓰는 법:** 특정 파일(들)을 가리키며 **"초보 리마인드"**라고 하면 — 나(Claude)는 **이 파일을 처음부터 다시 읽고**, 지시된 파일을 아래 체크리스트로 감사·보강한다. (매끄러운 "전문가-완결" 기본값을 끄는 스위치)

---

## ⛔ 먼저 버릴 기본값
- [ ] **정적 표 + 예제 1개 = "설명 끝"** 이라는 착각을 버린다. 입문자는 **한 번 봐선 응용 못 한다.**
- [ ] 목표는 *coverage(다뤘다)* 가 아니라 **transfer(다음 주에도 스스로 한다)**.
- [ ] 나는 입문자였던 적이 없어 **어디서 멈추는지 안 보인다** → 일부러 그 멈춤을 모델링한다.

## ✅ 3대 체크 (교육성 콘텐츠는 전부 통과)
1. [ ] 🧠 **오해 예측·정면돌파** — "여기서 입문자가 반드시 밟는 착각은?"을 먼저 묻고, 그 자리에서 부순다.
2. [ ] ⏱ **시간 시뮬레이션** — 한 번 설명으로 끝내지 않는다. 전환(`expr→값→truthy/falsy`, 메모리 이동, 프레임 push/pop, 배열 복사…)을 **다음 ▶로 밟는 step-through**로 재현. **기존 위젯 재사용**(`ExprReduce`·`MemoryModel`·`StackViz`) — 새로 안 만든다.
3. [ ] 🔁 **예측 → 반복** — 표/정답 보기 **전에 예측**(스포일러 없이) + **값만 바꾼 반복 드릴**로 손에 붙인다.

## 🧰 보조 규범
- [ ] 👁️ 시각화(대충 금지·실제와 맞게) · 🌍 정확한 현실 메타포 · ⌨️ 진짜 도는 코드(node/실행 검증) · 🔀 경계·대비("같은 그림 다른 코드" 등).
- [ ] 심화는 **선택** 표시. 개발 후 **실브라우저 스크린샷**으로 시각 검증.

## 🔗 판단 원리 (이 커리큘럼의 뼈대)
- **개념 그래프**: 챕터는 선이 아니라 얽힌 그래프. 각 개념은 **하나의 집(SSOT)**, 나머지는 **링크**. (예: 참·거짓/형변환 = `coercion` 한 곳, 3·4·7강이 링크)
- **관통 주제**: "값이 어디 사나(메모리)", "조건 = expr→ToBoolean" 같은 실을 여러 강에 관통시킨다.

---

## 감사 절차 (지시받으면)
1. **이 파일을 다시 읽는다.**
2. 지시된 파일을 3대 체크로 훑어 **"정적 표+예제1개"로 끝난 갭**을 찾는다.
3. 갭을 **짧게 보고** → 시뮬레이션+반복으로 **보강** → 실브라우저 검증 → 커밋.
