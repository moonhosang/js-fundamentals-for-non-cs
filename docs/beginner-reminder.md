# 🧒 입문자 리마인드 — 스위치 (짧게, 매 턴 재-앵커용)

> 이 파일은 **짧은 코어**다. 깊은 함정 카탈로그는 [`cognitive-audit-canvas.md`](cognitive-audit-canvas.md) (B 레지스트리).

## 🔔 큐잉 (한 문장이면 발동)
**`초보감사`** 라고 하면(별칭: `초보 리마인드` · `인지감사` · `CAC`) — 나는 **즉시 멈추고** 다음을 한다:
1. **이 파일 + `cognitive-audit-canvas.md` 를 실제로 다시 읽는다** (기억·각오 말고 파일을 읽어 재-앵커).
2. 지시된 파일을 아래 **코어 6 + 관련 함정(B)** 으로 감사한다.
3. "정적 표+예제 1개"로 끝난 갭을 **짧게 보고 → 시뮬레이션+반복으로 보강 → 실브라우저 검증 → 커밋.**

형식: `초보감사 <파일|강의id>` 또는 그냥 `초보감사`(현재/직전 대상).
왜 이런 스위치가 필요한가: 내 기본값(매끄러운 "전문가-완결")이 **매 턴 표류**하므로 — 당신이 한 문장으로 다시 규율로 끌어당긴다.

## ⛔ 먼저 버릴 기본값
- **정적 표 + 예제 1개 = "설명 끝"** 은 착각. 입문자는 **한 번 봐선 응용 못 한다.**
- 목표는 *coverage(다뤘다)* 가 아니라 **transfer(다음 주에도 스스로 한다)**.
- 나는 입문자였던 적이 없어 **어디서 멈추는지 안 보인다** → 일부러 모델링한다.

## ✅ 코어 6 (모든 교육성 콘텐츠가 통과)
1. 🧠 **지식의 저주 꺼** — 속도 1/3, `예측→실패→수정→반복` 순환.
2. 🕳️ **침묵 파내** — 초보가 질문조차 못 하는 위화감을 **내가 먼저 언어화**해 노출.
3. 🔄 **기억 재소환** — 선수 지식 가정 금지, 그 자리에서 메모리 모델 재활성화.
4. ⏱ **시간 시뮬레이션** — 한 번 설명 금지. 전환(`expr→값→truthy/falsy`, 메모리 이동, 프레임 push/pop…)을 step-through로. **기존 위젯 재사용**(ExprReduce·MemoryModel·StackViz).
5. 🔁 **예측 → 반복** — 표/정답 보기 **전에 예측**(스포일러 없이) + **값만 바꾼 반복 드릴**.
6. 🔗 **출구·연결** — 개념을 화면(DOM)·실전으로 잇고, SSOT/개념그래프로 다른 강과 링크.

## 🧭 판단 원리
- **개념 그래프**: 챕터는 선이 아니라 얽힌 그래프. 각 개념은 **하나의 집(SSOT)**, 나머지는 **링크**.
- **관통 주제**: "값이 어디 사나(메모리)", "조건 = expr→ToBoolean" 같은 실을 여러 강에 관통.
