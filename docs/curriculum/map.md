# 🗺️ 커리큘럼 지도

IT 전공자가 아닌 사람이 **완전 제로**에서 시작하는 실습형 JS 입문. 값 → 여러 값 → 화면 순으로 쌓는다.
상태: ✅ 완성 · 🚧 준비 중(계획만) · 📝 예정

> **파트 4개 + 레퍼런스.** 사이드바 순서와 일치. 원리 심화(메모리·그래프·클래스·콜스택)는 별도 트랙이 아니라 **자기 파트 안의 자연스러운 챕터**로 녹아 있다.
> - **파트 1 · 값과 메모리** = 1강 + 🧠 메모리 기초(값을 배웠으니 "그 값이 어디 사는가").
> - **파트 2 · 값 다루기와 함수** = 2·3·4·5강 + 🧠 메모리 심화(함수 뒤 콜스택·클로저·GC).
> - **파트 3 · 여러 값·반복·객체** = 6·7·8강 + 🕸️ 객체 그래프 + 🧬 클래스(객체 뒤).
> - **파트 4 · 화면을 움직이기** = 9·10강. **📚 레퍼런스** = 내장 기능.
>
> 이러면 사이드바 최상위는 **파트1~4만** 보여 흐름이 깔끔하고(예전엔 1강↔2강 사이에 심화 11개가 벽처럼 끼어 끊겼다), 파트를 펼치면 심화가 제 자리에 이어진다. 심화 개념 강의엔 "급하면 다음 파트로 건너뛰기" 배너(`DEEP_SKIP`)만 유지.
> 모든 챕터의 실습은 **난이도 3단계**(쉬움·보통·어려움 × 5 = 15문제, 난이도별 페이지 · [ADR 0008](../decisions/0008-tiered-drills-by-difficulty-files.md)).

## 파트 1 · 값과 메모리
- ✅ **1강 · 값과 타입, 변수** — 값 · **타입(원시/객체 두 부류)** · 이름표. (드릴 1-1…1-10) · "변수는 밥통이 아니라 이름표" 정면. 타입을 여기서 얕게 소개(원시 7·오토박싱·Java대비는 심화 한 줄) → **M4가 복제/참조의 예측 도구로 사용**. `typeof`는 여기서 인라인 소개(레퍼런스로 링크).

### 🧠 메모리 기초 (1강에 이어 · 급하면 2강으로 건너뛰기)
- ✅ **M1 · 메모리(Memory)** — 값이 사는 공간(주소·휘발성). 주소 붙은 칸 수십억 개. 주로 쓰는 종류가 RAM(안내 박스에 메모리 계층 위키 링크).
- ✅ **M2 · 스택** — 슬롯·LIFO·push/pop(StackViz)·"왜 사라져도 괜찮나" 6이유.
- ✅ **M3 · 힙** — 창고·주소·분류·왜 힙·❌스택에 뒀다면·거꾸로 원시값이 힙에.
- ✅ **M4-1 · 값 = 복사** — 이름표 착각 정면돌파(`let y=x`) · 속성 꺼내기(`a.num`)=복사 · 문자열 복사(개념 vs 엔진 interning 심화) · **불변**(model B: 재할당=화살표가 새 값 셀로 이동). 표기: 모든 값이 값 메모리 셀, 변수는 화살표 → [ADR 0007].
- ✅ **M4-2 · 참조 = 공유** — 별칭("왜 obj도 바뀌지") · **복제냐 참조냐(behavior 우선)** 예측 지도(타입은 1강 참조, 도구로 강등) · 가변성이 복사/공유를 가른다 · 묶음은 다 참조(Date·class). seam: `a.num`(복사)=M4-1 끝 / `a`(공유)=M4-2 시작.
- ✅ **M5 · 값에 의한 전달** — 원시값→함수, 복사본이라 원본 안전.
- ✅ **M6 · 참조에 의한 전달** — 객체→함수, 원본 바뀜.
- ✅ **M7 · 배열도 참조다** — 배열→함수, mutating vs 새 배열.

## 파트 2 · 값 다루기와 함수
- ✅ **2강 · 계산과 문자열** — 연산자·템플릿 리터럴·**형 변환 함정**.
- ✅ **3강 · 표현식** — 식 vs 문·우선순위·축약(reduction) (3-1…3-7, ExprReduce). 3-1에 if 설명+삼항 값-접힘 스텝퍼. 3-2 **BNF 생성규칙**(`expr→term|expr op term`, `factor→( expr )` 재귀). 3-4 축약②(함수·중첩삼항·혼합)+**축약 10선(★인식-밖 5)**. **3-6 · 조건도 표현식**(if·for·while·switch의 조건도 표현식, 완전 동일 축약). 3-7 요약. 3-3 메타포: 엉킨 실타래/단계별 산수.
- ✅ **4강 · 조건** — 비교·truthy/falsy·if·삼항.
- ✅ **5강 · 함수** — **단계(쇼츠) 5-1~5-7**: 왜 함수(반복 제거 동기) → 정의·호출 → 매개변수/인수 → return(vs print) → 🧠 프레임(메모리 in-place 복습) → 스코프 → 화살표·요약. 드릴 5-8~5-17. **배열·반복(map 콜백)·객체의 선수라 앞에.**

### 🧠 메모리 심화 (5강 함수에 이어 · 급하면 6강으로 건너뛰기)
- ✅ **콜 스택** — 함수의 삶과 죽음(push/pop).
- ✅ **클로저** — 사라지지 않는 스코프(makeCounter). ← 스택 성질의 예외. (시뮬레이션: count가 값 메모리로 '이사'·next() 호출마다 프레임 push)
- ✅ **가비지 컬렉션** — 아무도 안 가리키면 치운다. 순환 참조 함정. ← G4·불변과 연결.

## 파트 3 · 여러 값 · 반복 · 객체
- ✅ **6강 · 배열** — `[ ]`·인덱스·length·push·화면(칩 목록). 드릴 6-1~6-10.
- ✅ **7강 · 반복과 map** — for·forEach(반환X)·**map/filter/reduce**·오해(map이 원본 바꾼다) 정면돌파·map 메모리모델(새 배열은 힙 새 칸). 드릴 7-1~7-10.
- ✅ **8강 · 객체** — `{ key: value }`·점/대괄호·없는 키=undefined·중첩·배열 안 객체(실전 데이터)·메서드·힙 참조 공유(M4).
- ✅ **🎁 구조분해 `{ } [ ]`** — spread의 역(모양 맞춰 꺼내기). 객체=키(순서 무관·별칭·기본값)·배열=위치(건너뛰기·rest). 꺼낸 값은 M4 그대로(원시=복사·객체=주소). 함수 매개변수 구조분해·스왑. 드릴 3단계.
- ✅ **📦 JSON** — 객체↔문자열 왕복(stringify/parse). 저장·전송의 형태. **왕복=깊은 복사**(스프레드 얕은복사와 대비)·함정(함수·undefined 소실). 드릴 3단계.

### 🕸️ 객체 그래프 (8강 객체에 이어 · 급하면 9강으로 건너뛰기)
- ✅ **G1 · 별칭·중첩** — 효니 별칭(양방향)·2중 그래프·**같은 그림 다른 코드 / 같은 코드 다른 그림**.
- ✅ **G2 · 친구 목록** — 배열 안 사람 5명·참조 증명.
- ✅ **G3 · 계통도** — 가계도 트리·공유 지갑 차감·원시값 꺼내면 복사.
- ✅ **G4 · 친구 네트워크** — 순환(cycle). → GC 심화로 브릿지.

### 🧬 클래스 (8강 객체에 이어 · 급하면 9강으로 건너뛰기)
- ✅ **클래스** — "객체 찍는 틀". constructor·this·new·메서드·여러 인스턴스(각자 힙, M3·M4 메모리모델). **JS class = 프로토타입 위의 문법 설탕**(정직 프레이밍). 오해정면돌파: "class는 완전히 새로운 것"(→ 객체 위 문법). 드릴 3단계(쉬움/보통/어려움 — 상속·instanceof 포함).

### 🛟 에러 처리 (함수·객체 뒤 · 8강 TypeError 후속)
- ✅ **에러 처리 `try/catch/finally`** — 에러=던져지는(throw) 값. error-first Runner(안 잡으면 흐름 끊김)→try/catch로 붙잡기→e.name/e.message·throw new Error→콜스택 전파 MemoryModel→finally. 오해정면돌파: "try면 에러가 사라진다"·빈 catch 금지. 드릴 3단계(전파·재던지기·instanceof 포함).

### ⏳ 비동기 (콜스택·에러 뒤 · '시간' 축)
- ✅ **⏳ 뿌리 · 이벤트 루프는 왜 있나(`eventloop`)** — async 트랙 **최하층 '왜'**. 완전 제로 청중에 **프로그램·프로세스·스레드**부터(식당 비유: 프로세스=식당 한 채·스레드=요리사, 메모리 강+5강 콜스택 재소환). **싱글 스레드**(요리사 한 명·콜스택 하나) → **블로킹 실증**(busy-while로 페이지 얼림 Runner) → **위임**(🌐 Web API) → 콜스택 빔 → 큐에서 꺼냄 = **이벤트 루프**. 오해정면돌파: "JS는 멀티스레드로 진짜 동시". 심화: 싱글 스레드 거래(레이스 없음 ↔ 위임 필요)·run-to-completion. **EventLoopViz에 🌐 Web API 존 추가**(위임의 시각적 실체). → `async`로.
- ✅ **비동기 `setTimeout/Promise/async·await`** — 동기 vs 비동기 순서(Runner가 A·C·B 실증)·**이벤트 루프**(콜스택 비면 대기 큐에서 꺼냄, MemoryModel)·Promise/then·async/await(동기처럼 읽기). 오해정면돌파: "setTimeout(_,0)=지금"·"await=전체 정지". **순서 예측 Quiz 중심**(값-드릴은 포맷 부적합이라 생략 — 본문 노트). 이 강은 **입문 on-ramp**(대기 큐를 '하나'로 뭉뚱그림); 심화는 아래 3강으로 이어짐.
- ✅ **⏳ 심화 · 마이크로 vs 매크로 큐(`microtask`)** — "대기 큐 하나"를 🟣마이크로(Promise.then·await 뒷부분)·🟠매크로(setTimeout·이벤트) **둘로 분해**. 규칙: 콜스택 빌 때마다 🟣 전부 → 🟠 하나. 오해정면돌파: "먼저 등록=먼저 실행"·"setTimeout(0)이 제일 빠름". **전용 애니메이션 위젯 `EventLoopViz`**(큐 드레인) + **`DesugarViz`**(async/await → .then 사다리 풀기). 중첩·혼합 예측 Quiz ×3. **🖼️ 렌더 사이클 비트**(⑤): 한 바퀴=🟠매크로 하나→🟣마이크로 전부→🖼️렌더, "마이크로가 렌더보다 먼저"·마이크로 폭주/긴 동기가 렌더를 굶겨 화면 얼림·setTimeout으로 쪼개면 안 얼음(+setTimeout 최소~4ms 노트). EventLoopViz에 🖼️ 렌더 존 추가.
- ✅ **⏳ 병렬 · `Promise.all/race/allSettled/any`(`promiseall`)** — "Promise는 만들면 이미 시작" → 순차(await 줄줄이) vs 병렬(먼저 만들어 all). **실측 타이밍 Runner**(순차 ~1500 vs 병렬 ~500). **전용 위젯 `PromiseViz`**(가로 타임라인 동시 진행 + 모드 토글로 all↔race↔allSettled↔any 게이트 확정 시점 대비). fail-fast Quiz.
- ✅ **⏳ 오류 · 비동기 에러 전파(`asyncerr`)** — `try/catch`가 **콜백을 왜 못 잡나**(빈 콜스택서 나중 실행 → try/catch 이미 pop). `EventLoopViz`로 "try/catch가 콜백보다 먼저 사라짐" 애니. 해법: 콜백 안 try/catch · Promise `.catch` · `await`+try/catch(await가 rejection 재던짐) · `unhandledrejection`. **errors(콜스택 전파) × microtask(빈 콜스택) 교차 캡스톤.**

## 파트 4 · 화면을 움직이기
- ✅ **9강 · DOM** — querySelector(첫 하나)·textContent/style·createElement+append(7강 forEach 합체)·addEventListener(콜백)·실전 카운터. 드릴 9-1~9-10.
- ✅ **10강 · 실전 캡스톤** — 디지털 명함 카드 생성기. 새 문법 0, 배운 조각 조립(데이터→함수→반복→조건→DOM·이벤트). 졸업 실습 10-1~10-8(전 강 한 문제씩).

## 📚 레퍼런스
레퍼런스는 **두 종류**로 나눈다 — (1) 부르는 **도구**(내장 기능), (2) 언어의 **규칙**(참·거짓·형 변환). 도구는 분류별 서브페이지로 분리(아코디언), 규칙은 별도 항목(SSOT).
- ✅ **내장 기능(빌트인)** — `builtins`(개요) + 분류별 서브페이지 **① 타입·판별(`builtins-1`) · ② 숫자·수학(`-2`) · ③ 문자열(`-3`) · ④ 배열(`-4`) · ⑤ 객체(`-5`)**. 각 페이지에 표 + 실행 Runner + 이전/다음 내비. 드릴 `see:'builtins'`는 개요로 착지(분류 카드로 라우팅).
- ✅ **📐 참·거짓과 형 변환(`coercion`)** — truthy/falsy(falsy 딱 **8개**) + 캐스팅(명시적 `Number()`… + 암묵적 coercion)을 **도구가 아닌 '규칙'**으로 별도 분리. **SSOT**: 3강(3-4 coercion·3-6 truthy)·4강(조건 ③ falsy)이 모두 이리로 링크. `typeof`는 1강에서 `builtins-1`로 인라인 소개. **규범 풀 적용**(카탈로그 아닌 교육): 🔮 예측 Quiz → ⏱ 시간 시뮬레이션(ExprReduce ×2) → 🎯 반복 드릴 8문제. (도구 5페이지는 카탈로그라 표+Runner 경량 유지 — 교육은 6·7·8강이.)

## 설계 메모
- **심화를 파트 안으로 통합(2026-08 재구성)** — ①처음엔 심화(메모리·그래프·클래스)를 개념 직후에 끼운 **just-in-time**이었으나, 심화가 파트와 **동급 최상위 챕터**로 파트 사이에 끼어(1강 → 🧠M1~M7·🕸️G1~G4 벽 → 2강) 번호 흐름이 끊겼다. ②이를 "끝에 몰기"로 바꿨더니 심화가 본문과 **동떨어져** 부자연스러웠다. ③최종: 심화를 **자기 파트 안의 하위 챕터로 녹임** — 최상위는 파트1~4만, 파트를 펼치면 심화가 제 자리(1강 뒤 메모리, 8강 뒤 그래프·클래스, 5강 뒤 콜스택)에 이어진다. `DEEP_SKIP`로 "급하면 다음 파트로" 건너뛰기만 유지. (관련: [../decisions/0005-optional-deep-theory-with-skip.md](../decisions/0005-optional-deep-theory-with-skip.md))
- **전 강 완성** — 1~10강 + 메모리 기초/그래프/심화(콜스택·**클로저·GC**) 개념+실습(드릴) 완비. (클로저·GC는 `memory-advanced.js`에 구현 완료 — 위 챕터 목록 ✅와 일치. 이전 "📝 계획" 표기는 stale였음, 렌즈①/⑥ 감사에서 정정.)
- **함수를 5강으로 당김** — 함수는 배열·반복(map 콜백)·객체·콜스택의 **선수**라 앞으로. 메인 강의는 기초만(클로저·콜스택은 파트2 끝 메모리 심화에서).
