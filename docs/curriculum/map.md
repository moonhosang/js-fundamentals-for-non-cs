# 🗺️ 커리큘럼 지도

IT 전공자가 아닌 사람이 **완전 제로**에서 시작하는 실습형 JS 입문. 값 → 여러 값 → 화면 순으로 쌓는다.
상태: ✅ 완성 · 🚧 준비 중(계획만) · 📝 예정

> 사이드바 순서와 일치. 🧠/🕸️ 챕터는 **원리 심화(선택)** — 상단에 건너뛰기 배너.

## 파트 1 · 값·타입과 변수
- ✅ **1강 · 값과 타입, 변수** — 값 · **타입(원시/객체 두 부류)** · 이름표. (드릴 1-1…1-10) · "변수는 밥통이 아니라 이름표" 정면. 타입을 여기서 얕게 소개(원시 7·오토박싱·Java대비는 심화 한 줄) → **M4가 복제/참조의 예측 도구로 사용**.

## 🧠 메모리 기초 (선택·심화 · 1강 뒤)
- ✅ **M1 · 메모리(Memory)** — 값이 사는 공간(주소·휘발성). 주소 붙은 칸 수십억 개. 주로 쓰는 종류가 RAM(안내 박스에 메모리 계층 위키 링크).
- ✅ **M2 · 스택** — 슬롯·LIFO·push/pop(StackViz)·"왜 사라져도 괜찮나" 6이유.
- ✅ **M3 · 힙** — 창고·주소·분류·왜 힙·❌스택에 뒀다면·거꾸로 원시값이 힙에.
- ✅ **M4-1 · 값 = 복사** — 이름표 착각 정면돌파(`let y=x`) · 속성 꺼내기(`a.num`)=복사 · 문자열 복사(개념 vs 엔진 interning 심화) · **불변**(model B: 재할당=화살표가 새 값 셀로 이동). 표기: 모든 값이 값 메모리 셀, 변수는 화살표 → [ADR 0007].
- ✅ **M4-2 · 참조 = 공유** — 별칭("왜 obj도 바뀌지") · **복제냐 참조냐(behavior 우선)** 예측 지도(타입은 1강 참조, 도구로 강등) · 가변성이 복사/공유를 가른다 · 묶음은 다 참조(Date·class). seam: `a.num`(복사)=M4-1 끝 / `a`(공유)=M4-2 시작.
- ✅ **M5 · 값에 의한 전달** — 원시값→함수, 복사본이라 원본 안전.
- ✅ **M6 · 참조에 의한 전달** — 객체→함수, 원본 바뀜.
- ✅ **M7 · 배열도 참조다** — 배열→함수, mutating vs 새 배열.

## 🕸️ 객체 그래프 (선택·심화)
- ✅ **G1 · 별칭·중첩** — 효니 별칭(양방향)·2중 그래프·**같은 그림 다른 코드 / 같은 코드 다른 그림**.
- ✅ **G2 · 친구 목록** — 배열 안 사람 5명·참조 증명.
- ✅ **G3 · 계통도** — 가계도 트리·공유 지갑 차감·원시값 꺼내면 복사.
- ✅ **G4 · 친구 네트워크** — 순환(cycle). → GC 심화로 브릿지.

## 파트 2 · 값 다루기와 함수
- ✅ **2강 · 계산과 문자열** — 연산자·템플릿 리터럴·**형 변환 함정**.
- ✅ **3강 · 표현식** — 식 vs 문·연산자 우선순위·축약(reduction)·중첩 함수 (3-1…3-6 단계, ExprReduce).
- ✅ **4강 · 조건** — 비교·truthy/falsy·if·삼항.
- ✅ **5강 · 함수** — 정의·호출·매개변수/인수·return(vs print)·화살표·스코프 기초 + 호출=프레임 push 시각화(드릴 5-1…5-10). **배열·반복(map 콜백)·객체 메서드·메모리 심화가 전부 함수를 쓰므로 앞에 둔다.** 내부 원리(스택·전달·클로저)는 🧠 메모리 챕터로 forward-link.

## 설계 메모
- **메모리/그래프 심화가 크다** — 1강 뒤에 이론이 두툼. 그래서 "선택·건너뛰기"로 이탈 방지. (왜: [../decisions/0005-optional-deep-theory-with-skip.md](../decisions/0005-optional-deep-theory-with-skip.md))
- **미완성** — 7강 반복 · 8강 객체 · 9강 DOM · 10강 실전(실코딩 강의). 심화 이론과 별개로 채워야 함. (1~6강 + 메모리/그래프 심화는 완성.)
- **함수를 5강으로 당김** — 함수는 배열·반복(map 콜백)·객체·메모리 심화의 **선수**라 앞으로. 메인 강의는 기초만(클로저·콜스택은 메모리 심화에). 메모리 심화는 선택이라 함수 앞에 오지만 forward-ref로 "함수는 5강"을 안내.
