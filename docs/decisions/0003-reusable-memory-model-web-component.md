# 0003. 메모리 모델을 재사용 웹 컴포넌트로

**Status:** Accepted

## 맥락
입문자에게 메모리(값이 어디 사나)는 **매 개념마다** 다시 보여줘야 한다 — 참조·별칭·값전달·객체그래프·트리·순환·불변… 재사용 엔진이 없으면 개념마다 처음부터 그려야 하고, 결국 "말로만" 때우게 된다.

## 결정
`<memory-model>`을 **하나의 재사용 커스텀 엘리먼트**로 만든다(shadow DOM, 테마 토큰은 CSS 변수로 관통). 강의는 **시나리오 데이터(스냅샷 배열)** 만 넘긴다. 새 시각 요구가 생기면 레슨이 아니라 **엔진에 선언적 옵션**으로 흡수(person·items·faded·stackLabel 등이 그렇게 자람).

## 결과
- ➕ 이 컴포넌트 하나 + 시나리오로 **십수 개 개념**을 시각화. "매번 수고 들여 시각적으로"가 저비용으로 가능.
- ➕ 애니메이션·2층 토글·화살표 등 품질 개선이 **모든 강의에 일괄 반영**.
- ➖ 스냅샷을 손으로 짬 → 상태 복잡한 것(클로저·재귀)은 관리 비용 큼. 필요 시 "라인 실행 → 스냅샷 자동생성 인터프리터" 검토(백로그).
- ➖ SVG 화살표는 레이아웃 좌표 기반 → jsdom엔 안 그려짐(실브라우저 검증 필요).
- 형제 위젯: StackViz(스택 놀이터). 같은 철학으로 큐 등 확장 가능.
