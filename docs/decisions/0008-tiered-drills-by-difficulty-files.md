# 0008. 드릴을 난이도 3단계(쉬움·보통·어려움 × 5)로 · 난이도별 .js 파일 분리

Status: Accepted (refines [design-principles §3](../pedagogy/design-principles.md), [0005](0005-optional-deep-theory-with-skip.md))

## 맥락
지금까지 실습 드릴은 **"동일 유형 N문제(같은 난이도 반복)"** 였다 — 문자열 id 챕터는 한 페이지 stepped 5문제, 숫자 강의는 문제별 페이지 10개. 설계 규범 §3은 *"동일 유형=한 페이지, 난이도 점진=페이지 분리"* 를 이미 명시했지만, 실제로는 **점진 난이도 가지를 채우지 않아** 순수 반복에 머물렀다.

사용자 요청: *"동형 5문제 그러지 말고 난이도 쉬움/보통/어려움 각 5개씩 배치하라. 3개는 각 파일로 존재해야겠지."*

교육학적으로 순수 반복은 **automaticity(손 자동화)** 를 키우지만 **transfer(전이·응용)** 는 약하다. 반대로 난이도만 올리면 자동화 이전에 무너진다(productive failure의 실패 쪽). 둘 다 필요하다.

## 결정
**모든 챕터**(숫자 강의 1~10 + 메모리/그래프/심화 문자열 챕터 + 클래스)의 드릴을 **쉬움 5 · 보통 5 · 어려움 5 = 15문제**, **난이도별 3페이지**로 배치한다.

- **쉬움 5** = **동일 유형 반복**(자동화). 값만 바꿔 손에 붙인다. ← 기존 "동형 반복"의 자리.
- **보통 5** = 변형·조합(한 겹 더). 같은 개념을 살짝 다른 맥락에.
- **어려움 5** = 응용·전이(경계·함정·다개념 결합). ← §2-7 경계·대비, §5 마찰.
- **각 난이도는 별도 페이지**(사이드바 항목 3개: 쉬움/보통/어려움, 각 stepped ●○○○○ 5개).

**저장: 난이도별 실제 .js 파일로 분리.** 드릴 데이터를 레슨 파일에서 빼내 `src/drills/easy.js`·`normal.js`·`hard.js`로 옮긴다. 각 파일은 **모든 챕터의 해당 난이도**를 담는다:
```js
window.Drills = window.Drills || { easy: {}, normal: {}, hard: {} }
window.Drills.easy['8'] = { pattern, problems: [ …5개… ] }   // 8강 쉬움
window.Drills.easy['ram'] = { pattern, problems: [ …5개… ] } // 메모리 쉬움
```
app.js는 개념 강의마다 `<base>:easy`·`:normal`·`:hard` 3개의 `practiceset` 페이지를 파생한다.

## 왜 난이도별(가로) 분리인가 — 챕터별(세로)이 아니라
- **한 파일 = 한 난이도 렌즈.** "쉬움은 전부 순수 반복인가"를 파일 하나 훑어 검수할 수 있다(난이도 일관성 검증이 국소화).
- 난이도 정책을 바꿀 때(예: 어려움에 다개념 결합 강제) **파일 하나만** 훑으면 된다.
- 레슨 파일이 **개념 서술에만** 집중 → 파일이 짧아지고 관심사 분리(concept vs practice).

## 결과
- **얻는 것**: 자동화(쉬움)와 전이(어려움)를 **한 챕터 안에서** 모두. 학습자가 스스로 난이도를 고른다(§0005 자율·건너뛰기와 결). 난이도 검수가 파일 단위로 국소화.
- **잃는 것/비용**: 문제 수 급증(약 25챕터 × 15 ≈ **375문제**) — 전부 검증 필요. 레슨↔드릴 **파일 2곳**을 봐야 한 챕터를 이해(관심사 분리의 대가). 완화: **계약 테스트**([test/drills.html](../../test/drills.html))가 `window.Drills` 전 난이도를 real 브라우저로 일괄 채점.
- **마이그레이션**: 기존 문제를 **씨앗**으로 재활용 — 숫자 강의 기존 10문제 → 쉬움 5 + 보통 5, 어려움 5 신규. 문자열 챕터 기존 5문제 → 쉬움 5, 보통·어려움 신규.
- **규범 갱신**: §3의 "동일 유형=한 페이지"는 이제 **"쉬움 tier=동일 유형 반복(한 페이지) · 보통·어려움=분리 페이지"** 로 구체화.
- **불변 유지**: "문제에 답을 숨겨라"(§3), "진짜 도는 코드"(§2-5)는 전 난이도 공통. 어려움도 답 노출 금지.

## 대안(기각)
- **순수 반복 유지**(현행): transfer 약함 — 사용자 반려.
- **챕터별 파일 분리**(chapter/easy.js…): 파일 수 폭증(25×3), 난이도 일관성 검수가 흩어짐.
- **한 페이지에 15문제 stepped**: 클릭 피로는 적으나 난이도 경계가 흐려지고 "쉬움만 빠르게" 자율 선택이 안 됨.
