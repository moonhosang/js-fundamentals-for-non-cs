# 0002. 변수는 밥통이 아니라 이름표(alias)

**Status:** Accepted

## 맥락
"변수 = 값을 담는 상자/밥통(container)" 모델은 직관적이지만, 입문자 실패의 근원이다. 이 모델로는 **별칭**(왜 obj도 바뀌지?)·**불변**(money=200 변했잖아?)·**참조**가 전부 안 풀린다.

## 결정
전 커리큘럼에서 변수를 **값을 가리키는 이름표(alias/binding)** 로 가르친다. 언어도 통일: "담긴다/들어간다"(밥통) → "가리킨다/이름표를 붙인다"(alias). `=`는 "이 이름으로 가리켜라". 1강 도입부에 "⚠️ 변수는 밥통이 아니다" 명시.

## 결과
- ➕ 참조·별칭·불변·전달이 **한 모델**로 일관되게 풀린다. "무엇이 무엇을 가리키나"로 사고 유도.
- ➕ 재할당(money=200)을 "값 변신"이 아니라 "이름표가 다른 값을 가리킴"으로 정확히 설명.
- ➖ JS 정직한 뉘앙스 필요: 원시값은 이름이 가리키는 값이 복사·불변, 객체는 공유·가변. "변수=이름" 뼈대는 동일하다고 명시.
