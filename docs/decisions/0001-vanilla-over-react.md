# 0001. React/Vite 말고 바닐라 JS (빌드 없음)

**Status:** Accepted

## 맥락
초기엔 옆 프로젝트(리액트공부)를 참고해 React+Vite로 시작했다. 그런데 이건 **순수 JS를 가르치는** 커리큘럼이다. 학습자가 여는 레슨 파일이 죄다 `.jsx`라 "내가 배우는 언어"와 안 맞고, 빌드 도구가 입문자에게 불필요한 장벽이다.

## 결정
**바닐라 JS + 빌드 없음.** `index.html`이 클래식 `<script>`로 순서 로드(ES 모듈도 안 씀 → `file://` 더블클릭으로 실행). 레슨은 순수 `.js`.

## 결과
- ➕ 배우는 언어 = 레슨 파일 언어. 설치·빌드 0. 더블클릭 실행.
- ➕ 재사용 위젯을 팩토리 함수/커스텀 엘리먼트로 직접 제어(프레임워크 추상화 없음).
- ➖ 전역 스크립트 로드 순서를 수동 관리. 모듈 시스템·번들 최적화 없음(이 규모엔 문제 안 됨).
- 대안(기각): React 유지(모순), 초경량 라우터(불필요).
