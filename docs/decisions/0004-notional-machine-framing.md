# 0004. 스택/힙은 개념 모델(notional machine) + 실제 엔진 토글

**Status:** Accepted

## 맥락
JS는 C/자바와 달리 "원시값=스택, 객체=힙"이 **언어 명세가 아니다**(V8이 escape analysis·태깅으로 최적화). "원시값은 무조건 스택"이라고 단정해 그리면, 그게 바로 입문자에게 심는 **틀린 확신**이 된다 — 오해를 없애려다 오해를 만든다.

## 결정
메모리 모델을 **개념 모델(notional machine)** 로 명시 프레이밍한다: "실제 CPU가 이렇다"가 아니라 "이렇게 상상하면 코드 동작을 정확히 예측하는 일관된 모형". `<memory-model>`에 **[개념 모델] / [실제 엔진]** 2층 토글 — 엔진층에 V8 심화(SMI 태깅·히든클래스·escape) 주석.

## 결과
- ➕ 개념 모델 위에서 참조·불변·클로저가 전부 정확히 예측된다. 입문자 오해 최소화.
- ➕ 심화 학습자는 토글로 진짜 엔진 이야기까지.
- ➖ "이건 모델이지 하드웨어가 아니다"라는 프레이밍을 반복해서 상기시켜야 함(본문·컴포넌트 주석).
- 용어: notional machine(교육학/CS교육의 정식 개념).
