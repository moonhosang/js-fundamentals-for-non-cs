# 0005. 이론 심화는 선택 + 건너뛰기

**Status:** Accepted

## 맥락
사용자 요구로 메모리·객체그래프 이론이 깊고 넓어졌다(1강 뒤에 심화 십수 강). 개념은 훌륭하지만, IT 비전공 입문자가 **코드 한 줄 더 써보기 전에** 이론 11강을 통과해야 하는 이탈 위험이 실재한다.

## 결정
메모리 기초·객체 그래프·메모리 심화 챕터를 **선택(optional)** 으로 표시하고, 각 강의 상단에 **"원리 심화 파트 — 코드 급하면 N강으로 건너뛰기"** 배너를 둔다(`CHAPTERS`의 `optional:true, skipTo`). 이론을 지우지 않되, **자율·속도**를 준다.

## 결과
- ➕ 깊이(원하는 사람)와 진입장벽(급한 사람)을 동시에 만족. "언제든 돌아와" 신호.
- ➕ notional-machine-first 철학(원리 먼저)을 유지하면서 강제하지 않음.
- ➖ 커리큘럼 스파인이 선형이 아니게 됨(건너뛰기 경로 관리 필요).
- 구현 주의: 레슨이 host를 덮으므로 배너는 **별도 host div**로 분리(app.js renderPage).
