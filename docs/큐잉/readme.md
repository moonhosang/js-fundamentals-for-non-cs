# 🔔 큐잉 목록 — 복사해서 쓰세요

이 폴더는 **큐(cue) SSOT**입니다. 큐 하나면 AI가 "전문가-완결" 기본값을 끄고 입문자 인지 감사로 재-앵커합니다.

- **[초보감사.md](초보감사.md)** = 큐가 지정·실행하는 **실제 프롬프트**(코어 6 + 절차). 이 파일이 SSOT.
- **[인지-감사-캔버스.md](인지-감사-캔버스.md)** = 개념별 **함정 레지스트리**(B, 처리 위치 링크).

---

## ① 기본 — 특정 파일 감사 (복사)
```
초보감사 src/lessons/arrays.js
```
별칭(같은 동작):
```
초보 리마인드 src/lessons/arrays.js
인지감사 src/lessons/arrays.js
CAC src/lessons/arrays.js
```
슬래시(가장 결정적):
```
/초보감사 src/lessons/arrays.js
```
대상 생략 = 현재/직전 파일:
```
초보감사
```

## ② 여러 파일 / 강의 전체 (복사)
```
초보감사 src/lessons/objects.js src/lessons/dom.js
초보감사 6강
```

## ③ 파일이 안 실리는 환경(claude.ai 웹·앱·API)에서 (복사)
> CLAUDE.md·슬래시·메모리가 안 실리는 곳에선, 아래처럼 **프롬프트 파일을 직접 지정**하거나 그 파일 내용을 붙여넣으세요.
```
docs/큐잉/초보감사.md 를 읽고 그대로 실행해서 src/lessons/arrays.js 를 감사해줘
```

---

## ✅ 발동 확인 신호
큐가 걸리면 내 답변 **첫 줄**에 이게 찍힙니다:
```
[초보감사 발동 · 인지 감사 재독]
```
이게 안 보이면 큐가 안 걸린 것 → 다시 던지거나 `/초보감사`(슬래시) 사용.

## 🌐 어디서 먹나 (요약)
| 환경 | 먹음? | 근거 |
|---|---|---|
| Claude Code · 이 레포 안 (아무 세션) | ✅ | 프로젝트 `CLAUDE.md` + `/초보감사` 슬래시(레포 동봉) |
| Claude Code · 이 PC 다른 폴더 | ✅ | 전역 `~/.claude/CLAUDE.md` + 유저 슬래시(자체완결) |
| Claude Code · 레포 클론한 타 PC | ✅ | 프로젝트 파일이 레포 따라감 |
| claude.ai 웹·앱·API | ⚠️ 파일 안 실림 | 위 ③처럼 `docs/큐잉/초보감사.md` 붙여넣기 |
