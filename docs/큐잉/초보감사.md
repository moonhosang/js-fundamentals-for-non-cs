# 🔔 초보감사 — 인지 감사 프롬프트 (큐가 지정·실행하는 파일)

> **이 파일이 큐 `초보감사`의 전부다.** 모든 채널(프로젝트/전역 CLAUDE.md·슬래시·메모리)은 이 파일 **하나를 가리킨다**(SSOT). 문구를 바꾸려면 여기만 고친다.
> **파일이 안 실리는 환경**(claude.ai 웹/앱/API)에선 — 이 파일 전체(+ 옆의 `인지-감사-캔버스.md`)를 **붙여넣으면** 동일하게 작동한다. 그래서 "언제·어디서·어떤 세션이든" 이 파일만 지정하면 된다.
>
> **누구를·왜(who·why)는 [`../청중-포지셔닝.md`](../청중-포지셔닝.md)가 SSOT.** 이 규범(오해 정면돌파=scar-heal · 기초 제로부터=gap-fill)은 거기 정의된 **비전공 실무자** 청중에서 나온다.

## ▶ 실행 규칙 (초보감사 발동 시)
0. 출력 **첫 줄에 `[초보감사 발동 · 인지 감사 재독]`** 를 찍는다 (발동 가시 신호 — 침묵 실패 방지).
1. **이 파일 + 옆 `인지-감사-캔버스.md`(함정 레지스트리 B)를 실제로 읽어** 재-앵커한다(기억·각오 말고 파일을).
2. 지시된 대상(`초보감사 <파일|강의id>`, 없으면 현재/직전 대상)을 **코어 6 + 관련 함정(B)** 으로 감사한다.
3. "정적 표 + 예제 1개"로 끝난 갭을 **짧게 보고 → 시뮬레이션+반복으로 보강 → 실브라우저 검증 → 커밋.**
4. **C8 정합 스윕 리포트** (매 발동 필수·침묵 실패 방지) — 감사·보강을 마치면 [`인지-감사-캔버스.md`](인지-감사-캔버스.md) **C8의 4문**(함의·회수·병렬·자기규범)을 돌려 **표로** 보고한다:
   - **(a) 이번에 심은 씨앗** → 회수 예정 위치(seed→payoff 예약).
   - **(b) 아직 안 회수된 기존 씨앗** → 어느 강에서 회수할지.
   - **(c) 형제 강·드릴·시뮬에 빠진 병렬 처리**(방금 한 처리가 안 된 평행 지점).
   - **(d) 방금 만든/적용한 규범**을 전체에 소급할지 판단(맹목 복제 금지 — 안 맞는 자리는 스킵 사유 명시).
   비었어도 **"스윕: 0건"** 으로 찍는다(반응적 국소 완결 방지 = 이 프로세스 자체의 회귀 테스트).

## ⛔ 버릴 기본값
- **정적 표 + 예제 1개 = "설명 끝"** 은 착각. 입문자는 **한 번 봐선 응용 못 한다.**
- 목표는 *coverage(다뤘다)* 가 아니라 **transfer(다음 주에도 스스로 한다)**.
- 나는 입문자였던 적이 없어 **어디서 멈추는지 안 보인다** → 일부러 그 멈춤을 모델링한다.

## ✅ 코어 6 (모든 교육성 콘텐츠가 통과)
1. 🧠 **지식의 저주 꺼** — 속도 1/3, `예측→실패→수정→반복`.
2. 🕳️ **침묵 파내** — 초보가 질문조차 못 하는 위화감을 **내가 먼저 언어화**해 노출.
3. 🔄 **기억 재소환** — 선수 지식 가정 금지, 그 자리에서 메모리 모델 재활성화.
4. ⏱ **시간 시뮬레이션** — 한 번 설명 금지. 전환(`expr→값→truthy/falsy`, 메모리 이동, 프레임 push/pop…)을 step-through로. **기존 위젯 재사용**(ExprReduce·MemoryModel·StackViz).
   - **한 시나리오 = 실제로 밟는 경로 하나만.** 지금 값이 안 밟는 갈래(예: day=2인데 `default` 하이라이트)나 "만약 ~였다면" 반사실을 트래커에 섞지 마라 — 입문자는 실제 실행과 가정을 뒤섞어 혼란한다. 그 경로는 **그게 실제로 발동하는 별도 시나리오**로(예: day=0 → default).
5. 🔁 **예측 → 반복** — 표/정답 보기 **전에 예측**(스포일러 없이) + **값만 바꾼 반복 드릴**.
6. 🔗 **출구·연결** — 화면(DOM)·실전으로 잇고, SSOT/개념그래프로 다른 강과 링크.

> ➕ **C7 정곡 격파·아낌없이** · **C8 정합 스윕** — 나중에 추가된 상시 코어(캔버스 (A) C7·C8 참조). C7=한 오개념당 여러 각도로 마구 생성(사용만이 아니라 생산·선언도). C8=변경 후 4문 스윕(위 실행 규칙 4단계로 **매 발동 리포트**).

## 🧭 판단 원리
- **개념 그래프**: 챕터는 선이 아니라 얽힌 그래프. 각 개념은 **하나의 집(SSOT)**, 나머지는 **링크**.
- **관통 주제**: "값이 어디 사나(메모리)", "조건 = expr→ToBoolean" 같은 실을 여러 강에 관통.
