# 🌱 IT 전공자가 아닌 사람을 위한 JS 입문

일은 하고 있지만 전공자가 아니라 기초가 없어 답답한 사람을 위한, 읽고 → 눌러보고 → 직접 고치며 배우는 실습형 자바스크립트 커리큘럼.

**"돌아는 가는데 왜 이렇게 동작하는지 모르겠다"** 를 정면으로 집는다 — 값이 **메모리(스택·힙)에서 어떻게 사는지**, 한 줄의 식이 **어떻게 한 겹씩 계산되는지**를 단계별 애니메이션으로 눈으로 본다. 매 개념마다 규칙을 명시하고 → 라이브로 실증하고(버튼·▶ 스텝) → 같은 유형 문제로 손에 붙인다.

**빌드가 없다.** 프레임워크도, 번들러도 필요 없다 — 순수 바닐라 JS라 `index.html`을 열면 끝이다. (순수 JS를 배우는데 앱이 프레임워크인 건 모순이니까.)

▶ **라이브 데모**: https://moonhosang.github.io/js-fundamentals-for-non-cs/ (GitHub Pages 자동 배포. `main`에 push하면 갱신된다.)

## 🚀 실행 — 설치가 필요 없다

Node.js도, 빌드도 필요 없다. 셋 중 아무거나:

1. **가장 쉬운 법** — `index.html`을 브라우저로 더블클릭한다.
2. **로컬 서버** (선택) — 폴더에서 아래 중 하나:
   ```bash
   npx serve .
   # 또는
   python -m http.server 8000
   ```
3. **온라인** — 위 라이브 데모 링크를 연다.

## 📚 무엇을 배우나

- **파트 1~2** — 변수(값에 붙이는 이름표) · 계산과 문자열 · **표현식**(한 줄을 나무로 분해·축약) · 조건 · 배열
- **🧠 메모리 기초** — RAM · 스택 · 힙 · 값 복사 vs 참조 · 값/참조에 의한 전달
- **🕸️ 객체 그래프** — 별칭 · 계통도(트리) · 순환 · 콜 스택
- 이론이 급하지 않으면 각 심화 챕터의 **"건너뛰기"** 배너로 실습부터 시작할 수 있다.

## 🧩 구조

빌드 없이 `index.html`이 클래식 `<script>`로 순서대로 불러온다.

| 경로 | 역할 |
| --- | --- |
| `src/lib/` | 재사용 위젯 — `memory-model`(스택/힙 시각화) · `exprreduce`(표현식 축약) · `runner` · `drill` · `stackviz` |
| `src/lessons/` | 강의별 콘텐츠 (`window.Lessons[id]`) |
| `src/app.js` | 사이드바 · 해시 라우팅 · 진도 |
| `docs/` | 설계 문서 + ADR(아키텍처 결정 기록) |

## ⚙️ 배포 (GitHub Pages)

빌드가 없으니 CI(빌드 로봇)도 필요 없다. 저장소 **Settings → Pages → Build and deployment → Source** 를 **Deploy from a branch**, 브랜치는 **`main` / `(root)`** 로 지정하면 끝이다. 이후 `main`에 push할 때마다 GitHub가 정적 파일을 그대로 다시 게시한다. (`.nojekyll` 파일이 있어 Jekyll 처리 없이 원본 그대로 서빙된다.)
